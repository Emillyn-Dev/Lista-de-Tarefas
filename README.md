# Lista-de-Tarefas

Gerenciador de Tarefas em Python 📝

Este é um gerenciador de tarefas simples feito em Python, projetado para organizar suas atividades de forma prática e interativa no terminal.

Ele permite que você: <br>

✅ Adicione tarefas com título e descrição

📋 Liste todas as tarefas, mostrando se estão concluídas ou pendentes com os símbolos ✅/❌

❌ Remova tarefas pelo número da lista

✏️ Edite tarefas, alterando título e descrição

🔄 Marque ou desmarque tarefas como concluídas, alternando entre ✅ e ❌

🛑 Saia do programa de forma segura com a opção 0

O projeto utiliza estruturas básicas do Python, como listas, dicionários, loops while e condicionais if/elif/else
